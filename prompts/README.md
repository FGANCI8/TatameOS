# Renova Aura Prompt System

This folder contains the persistent operating system for agents working in TatameOS.

## Mandatory rule
No work starts before the mandatory skill system is consulted.
No code change is allowed before the mandatory order below is read in sequence.
No task is considered done without honest validation.

## Then read domain skills
- Choose the domain by task type.
- Read the matching skills before editing anything.
- Use the maps, contracts, standards, and runbooks when the task touches flows, envs, data, or release.
- Legacy trees are documented in [skills/LEGACY.md](./skills/LEGACY.md) and are not primary reference.
