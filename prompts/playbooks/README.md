# Playbooks

This folder is the living library for repeatable execution playbooks.

## Use
- Store task-specific sequences here when a reusable procedure matters.
- Keep playbooks concrete, short, and safe to repeat.
- Pair with [templates/playbook-template.md](../templates/playbook-template.md) when drafting a new playbook.

## Principle
Playbooks should reduce ambiguity and keep execution honest.
