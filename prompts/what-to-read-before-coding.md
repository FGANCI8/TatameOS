## Then choose the domain
- Routing change: read routing skills and route maps.
- UI change: read frontend, UX, design system, and copy skills.
- Backend change: read backend and integration skills.
- Data change: read data and tenant skills.
- Performance change: read performance and observability skills.
- Release change: read release, CI/CD, testing, and monitoring skills.
- Growth change: read product, growth, UX, and copy skills.

## Before coding, inspect
- maps
- contracts
- standards
- runbooks
- checklists
- relevant current files in the workspace

## Principle
The right reading sequence prevents the wrong change.
