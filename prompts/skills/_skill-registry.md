## Domain map
- Core: operating rules, truthfulness, risk control, stop conditions.
- Orchestration: task routing, conflict resolution, parallel execution.
- Architecture: boundaries, modules, dependency control.
- Routing: flows, dead-route detection, access validation.
- Frontend: visual system, feedback, responsiveness, state visibility.
- Design system: tokens, brand, color reference sync, visual consistency.
- UX: journeys, onboarding, friction, state semantics.
- Copy: CTA clarity, trust language, product messaging.
- Backend: validation, async control, providers, function evolution.
- Integrations: optional services, graceful degradation, env-aware init.
- Security: secrets, auth integrity, unsafe fallback elimination.
- Tenant: isolation, source of truth, cross-tenant leak prevention.
- Data: drift, schema evolution, query shape, write/read contracts.
- Performance: render, network, waterfall, loading budget.
- Testing: coverage, E2E, smoke, reproducibility, emulator honesty.
- CI/CD: pipeline gating, artifacts, deployment safety.
- Observability: logs, anomaly detection, silent failure detection.
- Product: priority, coherence, MVP scope, value delivery.
- Growth: activation, retention, value proposition, conversion surface.
- Research: external patterns, benchmark adaptation, change awareness.
- Refactoring: safe refactor, isolation, simplification, duplication removal.
- Release: readiness, rollback, env integrity, final diff review.
- Recovery: incident triage, hotfix safety, postmortem discipline.
- Feedback loop: signals, telemetry, issue-to-fix routing.
- Playbooks: how-to procedures for task execution and validation.
