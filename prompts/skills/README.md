# Skills System

This directory is the persistent operating layer for future agents.

## Mandatory rule
No work starts before the mandatory consultation protocol is read.
No code change is allowed before the minimum sequence is followed.
No task is done until validation is honest.

## How to use
- Start with [./_entry-router.md](./_entry-router.md).
- Start with the mandatory consultation protocol.
- Read [../start-here.md](../start-here.md) before anything else.
- Follow the minimum sequence listed in [../start-here.md](../start-here.md).
- Use the registry to find the domain skills.
- Read the activation order before deciding which skills to fire.
- Resolve conflicts using the conflict-resolution policy.
- Choose additional skills only after the task type is classified.
- Validate honestly before closing the task.
